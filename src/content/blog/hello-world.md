# 你好，世界！🌍

这是我的第一篇博客文章，也是 **mowan-portfolio** 作品集网站的诞生记录。

## 为什么要做作品集？

作为一个开发者，我一直觉得需要一个地方来展示自己的项目和成长历程。GitHub 虽然能展示代码，但缺少一些东西：

- **故事性** — 项目背后的思考和决策过程
- **视觉呈现** — 截图、图表、交互式展示
- **品牌感** — 统一的风格和个人标识

作品集网站就是解决这些问题的答案。

## 技术选型

这个作品集使用了我目前最感兴趣的技术栈：

| 技术 | 用途 | 选择理由 |
|------|------|----------|
| **Vue 3** | 前端框架 | 组件化、Composition API 优雅 |
| **Vite** | 构建工具 | 极速热更新、TypeScript 原生支持 |
| **UnoCSS** | CSS 框架 | 按需生成、极轻量、灵活 |
| **Pinia** | 状态管理 | 类型安全、Vue 3 官方推荐 |
| **GitHub Pages** | 部署 | 免费、与 GitHub 生态集成 |

## 设计理念

我选择了**暗色系毛玻璃风格**，原因很简单：

1. **开发者友好** — 暗色模式是开发者的日常
2. **内容聚焦** — 减少视觉干扰，让项目本身说话
3. **现代感** — 毛玻璃效果 + 紫罗兰渐变，有一种科技感

## 后续计划

这个作品集不会止步于此，我计划：

- ✅ 项目展示 + 筛选功能
- ✅ 学习路线时间线
- 📝 持续写博客，记录学习笔记
- 🔜 接入 GitHub API 自动同步仓库数据
- 🔜 添加更多动画和交互效果

## 结语

"Show, don't tell." 作品集就是最好的证明。

如果你也在搭建自己的作品集，欢迎交流！🎉
